01 Overview & Concept

ทำไมเลือกขายดอกไม้? ร่าง · ทีมช่วยเขียน

Atelier de Flora = ร้านดอกไม้ออนไลน์ ซื้อช่อสำเร็จรูป, ออกแบบช่อเอง และให้ AI ช่วยเลือก

ของขวัญต้องเป็นส่วนตัว

ช่อดอกไม้มักซื้อให้คนสำคัญ ลูกค้าอยากเลือกเองว่าจะใส่ดอกอะไร กี่ดอก → Custom design

คนส่วนใหญ่เลือกไม่เป็น

ไม่รู้ว่าดอกไหนเหมาะกับโอกาสไหน หรือได้กี่ดอกในงบเท่านี้ → Ask AI ช่วยจัดช่อตามงบ

มีโอกาสซื้อทั้งปี

วันแม่, วาเลนไทน์, รับปริญญา, วันเกิด, แสดงความยินดี: ความต้องการต่อเนื่อง ไม่ใช่สินค้าตามฤดูกาลอย่างเดียว

โจทย์เทคนิคที่น่าสนใจ

ช่อ 1 ช่อ = วัตถุดิบหลายอย่าง (recipe + inventory) ราคาต้องคำนวณ ไม่ใช่สินค้าชิ้นเดียวธรรมดา

  Customer

ดู/ค้นหาสินค้า · ออกแบบช่อ · ตะกร้า + gift note · จ่าย PromptPay · dashboard (ที่อยู่, ช่อที่เซฟ, ประวัติ) · ถาม AI

  Admin

05 Authentication

JWT ใน httpOnly cookie

Registerbcrypt hash password
Loginตรวจรหัส → ออก JWT 2 ใบ
httpOnly cookiebrowser แนบให้เองทุก request
authenreq.user = { userId, role }
authorize(["admin"])เฉพาะ route ของแอดมิน

2 tokens

accessToken 15 นาที { userId, role }
refreshToken 7 วัน เก็บใน DB ด้วย → logout แล้วใช้ต่อไม่ได้

Refresh อัตโนมัติ

accessToken หมดอายุ → axios interceptor เรียก /auth/refresh ให้เอง ผู้ใช้ไม่ต้อง login ใหม่ · เปิดเว็บเช็ค GET /auth/me

ทำไมใช้ httpOnly

JavaScript ในหน้าเว็บอ่าน token ไม่ได้ ลดความเสี่ยง XSS · บัญชี suspended login ไม่ได้ (403)

Forget / reset password: ตอนนี้ใช้รหัสยืนยันจำลอง ยังไม่ส่งอีเมลจริง วิทวัสเช็ค

Notes: ถ้าถูกถาม: refresh token บน production ยังตั้ง sameSite: "strict" ข้ามโดเมน Vercel → Render ไม่ได้ กำลังแก้เป็น "none"
